# Support

## Getting help

- **Documentation:** see the `docs/` directory.
- **Issues:** search existing issues before opening a new one.
- **Discussions:** use GitHub Discussions for questions and ideas.

## Response time

There is no service-level agreement at this stage. Responses are best-effort.

## Security issues

For security vulnerabilities, see [SECURITY.md](SECURITY.md). Do not use
public issues.
