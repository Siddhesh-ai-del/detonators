# Security Policy

## Supported versions

Security fixes are applied to the latest release on the `main` branch. Older
versions are not supported.

## Reporting a vulnerability

Please report security vulnerabilities privately via GitHub's security
advisory feature on this repository ("Security" tab -> "Report a vulnerability").

Do not open public issues for security vulnerabilities.

## Scope

In scope:
- Authentication and session handling
- Data access and authorization
- Input validation and injection
- Secrets management

Out of scope:
- Denial of service against third-party services
- Social engineering
- Issues in dependencies that are already publicly disclosed

## User guarantees

- We will acknowledge receipt of a report within 72 hours.
- We will provide a fix or mitigation plan within 30 days for confirmed issues.
- We will credit reporters in the changelog unless they prefer anonymity.

## Disclosure

We follow coordinated disclosure. Please allow us reasonable time to address
the issue before public disclosure.
